# Gemensamt repository

Ett gemensamt repository används som en centralt fillsystem som flera personer har tillgång till och kan både dra och skicka filer till.
Repositoryt används att hålla alla filer, dokumentationer och konfigurationer på ett och samma ställe för alla som ska arbeta på samma projekt.
Det går att skapa flera "branches" för att kunna arbeta eller testa funktioner innan man mergar dem in i main branchen igen vilket möjliggör att kunna testa nya funktioner eller riskabla ändringar utan att påverka main branchen som andra arbetar på.
I ett repository finns det också historik vilket gör att man kan se de exakta ändringar andra har gjort.
