# kunskapskontroll 2

---

Den här uppgiften kontrollerar att du kan använda grundläggande utvecklingsverktyg och arbetsflöden i enklare moment. Fokus ligger inte på avancerad programmering, utan på att du ska kunna orientera dig i filsystemet, använda terminalen, arbeta i en utvecklingsmiljö och förstå grunderna i Git och repository-samarbete.
